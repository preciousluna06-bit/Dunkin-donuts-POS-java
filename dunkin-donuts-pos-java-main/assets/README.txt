HOW TO ADD ITEMS
1. Drop the picture (png/jpg) into the matching category folder, e.g. assets/Donuts/glazed.png
2. Open menu.csv and add/edit a line:  Category,Name,Price,ImageFile
   (A picture NOT listed in menu.csv is still shown automatically, priced at default.price.)
3. New category? Create a new folder under assets/ and use the same name in menu.csv.
4. Optional: assets/logo.png replaces the text logo in the header.
5. Store name, VAT, cashier etc. are in config.properties.
Restart the program after changes.
